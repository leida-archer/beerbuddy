# BeerBuddy

A mobile-first PWA that surfaces the **best beer deals at stores in Nevada County, CA** — ranked by deal-vs-baseline (not just sticker-cheapest), updated weekly from chain websites, weekly ads, and delivery aggregators.

## What this is

You open the app on a Friday afternoon. Enter your ZIP. See one ranked list of this week's genuinely-best beer deals at the six chains within ~25 miles of Grass Valley / Nevada City — Raley's, Save Mart, Grocery Outlet, Holiday Market, SPD, BevMo Auburn — plus indie liquor stores covered via DoorDash / Caviar / Toast. Tap the deal you want, get directions, drive there.

Differentiator: every price is judged against its 90-day median for that product. A beer that's chronically cheap doesn't crowd out a real deal on a beer that's normally pricier. Cheapest filters; deal-vs-baseline persuades.

## Stack (v1 plan)

- **Frontend:** Next.js (App Router) PWA · Tailwind · deployed on Vercel free tier
- **Backend:** Next.js API routes · Postgres on Neon · Drizzle ORM + drizzle-kit migrations
- **Ingestion:** GitHub Actions cron orchestrator running TypeScript adapters. **Default engine: Playwright (headless Chromium)** — most chain sites are SPAs. Plain `fetch` reserved for PDF circulars and SSR pages. Sources that can't be auto-parsed (PDF-only circulars, captchas, layout regressions) are written to a `manual_parse_queue` table that surfaces in `/admin/parse-queue`; the admin handles those out-of-band.
- **a11y baseline:** WCAG 2.1 AA from day 1.

## Product principle (non-negotiable)

The user never works to make BeerBuddy better. No "submit a price," no surveys, no upload UI in public surfaces. All data is sourced from the web by the developer. See [`DESIGN.md`](./DESIGN.md) § Product Principle: Zero User Labor.
